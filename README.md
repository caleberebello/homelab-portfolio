## 🖧 Homelab de Infraestrutura de Redes

Este repositório documenta meu ambiente de laboratório, onde coloco serviços que uso em casa, ao passo que testo serviços para aumentar minha experiência profissional.

## 🎯 Objetivo
Desenvolver e demonstrar habilidades práticas em:
- Infraestrutura de redes
- Firewall e roteamento (Mikrotik)
- Serviços internos (DNS, Cloud, Web)
- Virtualização (Proxmox)
- Backup e recuperação de dados
- E quem sabe melhorar minha rede doméstica.

## 🧱 Infraestrutura Física

- Desktop Dell com 16GB RAM DDR4 e 1TB de HDD rodando Proxmox
- Desktop Dell com 8GB RAM DDR4 e 1TB de HDD rodando TrueNas
- Switch de mesa (rede local)
- Roteador (modo Access Point)
- Mikrotik RB760iGS (firewall e roteamento principal)

## 🖥️ Infraestrutura Virtual (Proxmox)

### 🔹 Serviços de rede
- Pi-hole (DNS e bloqueio de anúncios)

### 🔹 Monitoramento / Dashboard
- Homepage (dashboard interno)

### 🔹 Serviços de aplicação
- Pterodactyl (gerenciamento de servidores)
- Servidor Minecraft (VM dedicada)

### 🔹 Armazenamento e Backup
- Nextcloud (armazenamento privado)
- Duplicati (backup automatizado para TrueNAS)

### 🔹 Web / Proxy
- Nginx (servidor web)
